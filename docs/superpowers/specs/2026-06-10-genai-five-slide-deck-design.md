# GenAI 五頁課堂簡報設計規格

## 目標

使用 `1142 GenAI 期末個人專題簡報模板.pptx` 製作約五頁、可於 2026-06-11 課堂報告的初版簡報。簡報聚焦 GenAI 如何協助完成個人網站，並整合三個主題：

- Frontend Design Prompt
- Skills / Workflow
- Learning Trace

## 核心論點

個人網站不是單純由 AI 生成的成果，而是一個透過結構化 Prompt、Skills 工作流與反覆驗證完成的 GenAI 前端協作案例。

## 受眾與時間

- 受眾：生成式人工智慧導論授課教師與同學
- 報告時間：約 5 分鐘
- 頁數：5 頁
- 語言：繁體中文為主，保留必要英文術語

## 模板規則

- 必須從老師原始 PPTX 複製既有投影片骨架，不從空白簡報重畫。
- 保留校徽、藍色頁首頁尾、課程名稱、頁碼與微軟正黑體系統。
- 刪除所有模板教學文字、Reddit Avatar、範例文獻與 Thank You 圖。
- 每頁必須有頁碼。
- 網站截圖使用目前本機網站的 Home、Projects、Resume 實際畫面。

## 五頁敘事

### 第 1 頁：封面

- 標題：以 GenAI 建立前端設計協作流程
- 副標：Prompt Engineering、Skills Workflow 與個人網站實作
- 作者：黃偉閎
- 功能：建立題目與個人身份，不堆疊細節。

### 第 2 頁：成果全貌

- Claim：成果是一套完整個人品牌網站，而不是單一頁面
- 證據：Home、Projects、Resume 三張網站截圖並排
- 補充：Next.js 16、RWD、互動視覺、內容元件化

### 第 3 頁：Frontend Design Prompt

- Claim：結構化 Prompt 將抽象風格轉成可執行前端規格
- 左側內容：
  - Purpose：個人品牌與專案展示
  - Visual Direction：黑色極簡、glass、動態背景
  - Constraints：Next.js、RWD、中文字體、可讀性
  - Acceptance：資訊階層清楚、三頁一致、可操作
- 右側證據：Home 首頁截圖

### 第 4 頁：Skills Workflow

- Claim：Skills Workflow 將生成結果變成可驗證工程流程
- 流程：需求拆解 → Brainstorming → Frontend Design → Implementation → Browser Verification
- 證據：Projects 頁截圖
- 說明：Skills 不是功能清單，而是不同階段的品質控制。

### 第 5 頁：Learning Trace

- Claim：每次修改都形成可說明的學習證據
- 表格欄位：階段、初始問題、修正方式、學習結果
- 例子：
  - 視覺過於通用 → 強化設計限制 → Prompt 必須定義風格與反例
  - 內容只有畫面 → 補上 Projects / Resume → 成果需要完整資訊架構
  - 修改後未驗證 → 使用 Browser 截圖 → 必須以實際畫面驗收
- 證據：Resume 頁截圖
- 結尾：後續擴充為 15–20 頁正式簡報與 10–15 頁 Word 報告。

## 截圖配置

- Home：封面或 Prompt 頁主視覺，保留姓名、照片、技術標籤與 CTA。
- Projects：Workflow 頁，保留 QuantSense 與 TokenPay 卡片。
- Resume：Learning Trace 頁，保留學校、排名、技能與聯絡資訊。
- 三頁總覽：第 2 頁並排，裁切比例一致。

## 驗收標準

- 最終檔案為可編輯 PPTX。
- 恰好 5 頁。
- 沒有模板範例文字或圖片殘留。
- 截圖不變形、不模糊，裁切重點清楚。
- 字體、頁首頁尾、頁碼與老師模板一致。
- 渲染後沒有文字溢出、遮擋或低對比。
